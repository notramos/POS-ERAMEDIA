## BUG BARU: Keyboard Shortcut Mengganggu Input Form

### Laporan Bug
**Bug**: Saat user mengisi form jumlah bayar (paid_amount) atau diskon, keyboard shortcut angka (1-9) tetap ter-trigger sehingga tidak bisa input nominal yang diinginkan.

**Cause**: Keyboard event listener tidak memeriksa apakah user sedangfocus di input field.

### Solusi yang Direkomendasikan

#### 1. Perbaiki Keyboard Shortcut - Ignore saat di Input Field
Modifikasi `document.addEventListener('keydown')` di `create.blade.php`:
- Tambah pengecekan: jika `e.target` adalah input/textarea, skip shortcut
- Contoh: `if (e.target.tagName === 'INPUT' || e.target.tagName === 'TEXTAREA') return;`

#### 2. Hapus Tombol Tambah/Kurang pada Tabel Produk
Berdasarkan request user, hapus tombol `-` dan `+` pada qty stepper di tabel produk karena:
- Membuat UI ruwet
- User lebih suka klik tombol add (berwarna hijau) langsung

**Implementasi**:
- Hapus `qty-btn-minus` dan `qty-btn-plus` dari `<div class="qty-stepper">`
- Hanya pertahankan input number dan tombol add (+)

## BUG BARU: Tombol Tambah Tidak Horizontal

### Laporan Bug
**Bug**: Tombol tambah (+) pada tabel produk masih belum horizontal/sejajar dengan input qty.

**Kemungkinan Cause**:
1. Ada CSS dari parent container (table-cell) yang overwrite display
2. vertical-align tidak konsisten pada td
3. Bootstrap table可能有 overriding styles

### Solusi yang Direkomendasikan

1. **Tambah `vertical-align: middle` pada `<td>` yang berisi qty-stepper**

2. **Tambah CSS khusus untuk memastikan inline:**
```css
.qty-stepper {
    display: inline-flex !important;
}
```

3. **Pastikan tidak ada wrapper `d-flex` yang mengapit:**
- Cek apakah ada `class="d-flex gap-1 align-items-center"` yang masih tersisa

---

- Check dan fix CSS: 5 menit
- **Total: ~5 menit**
