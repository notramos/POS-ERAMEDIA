# Plan: Ubah Logic Loading & Select Barang di Modal Tambah Produk

## Goal
Saat pilih supplier, load data dari API tapi tampilkan placeholder (tidak auto-select).

## Current Behavior (yang perlu diubah)
1. Pilih supplier → langsung fetch API & auto-select item pertama (index 1)
2. Langsung trigger check-existence untuk item pertama

## Desired Behavior (User's Request - Terbaru)
1. Pilih supplier → Load data dari API
2. Dropdown select menampilkan placeholder "-- Pilih Barang --" (index 0, value kosong)
3. User harus klik dropdown dan pilih salah satu barang (index 1+)
4. Pilih barang → trigger check-existence dan update UI

## Perubahan yang Diperlukan

### 1. File: `resources/views/product/product.blade.php`

#### A. Event handler supplier change
- Load data dari API seperti sekarang
- Set placeholder sebagai option pertama dengan value kosong
- Enable select setelah data loaded

```javascript
$('#productSupplier').change(function() {
    const supplierId = $(this).val();
    $('#selectedSupplierId').val(supplierId);
    const select = $('#supplierItemSelect');
    
    if (!supplierId) {
        select.empty().append('<option value="">-- Pilih Supplier --</option>').prop('disabled', true);
        // reset fields
        return;
    }
    
    select.empty().append('<option value="">Memuat...</option>').prop('disabled', true);
    
    $.get(`/products/supplier-items/${supplierId}`, function(data) {
        select.empty();
        if (data.length === 0) {
            select.append('<option value="">Tidak ada barang</option>');
        } else {
            // Placeholder sebagai option pertama
            select.append('<option value="">-- Pilih Barang --</option>');
            data.forEach(item => {
                select.append(`
                    <option value="${item.name}" 
                            data-stock="${item.stock}"
                            data-price="${item.purchase_price}">
                        ${item.name} (${item.unit_name || '-'})
                    </option>
                `);
            });
        }
        select.prop('disabled', data.length === 0);
    });
});
```
