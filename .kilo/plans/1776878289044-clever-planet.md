# Plan: Perubahan Logika Pembelian & Tambah Product

## Tujuan
1. **Pembelian**: Jika barang sudah ada di `products` → langsung tambah stock. Jika baru → masuk ke `supplier_items` saja.
2. **Modal Tambah Product**: Tampilkan hanya supplier_items yang belum ada di products, dengan field margin untuk menghitung harga jual otomatis.

---

## Langkah 1: Modifikasi PurchaseService (`app/Services/PurchaseService.php`)

### Saat ini:
- Untuk `items` (existing supplier_items): selalu increment stok di `supplier_items`
- Untuk `new_items`: buat product baru jika tidak ada

### Menjadi:
- Untuk setiap item yang di-purchase:
  1. **Cek apakah produk sudah ada** di `products` dengan nama yang sama + supplier_id sama
  2. ** Jika ADA**: 
     - Langsung increment stock di `products`
     - Optional: increment juga stok di `supplier_items` (biarkan stok supplier tetap)
  3. ** Jika TIDAK ADA**:
     - Hanya increment stok di `supplier_items` (produk tunggu di "antrian")
     - Jangan buat produk baru otomatis

### Kode spesifik:
```php
// Di dalam loop foreach ($data['items'] ?? [] as $itemId => $item)
// Hapus: $supplierItem->increment('stok', $quantity);

// Tambahkan logika:
$product = Product::where('supplier_id', $supplierId)
    ->where('name', $supplierItem->name)
    ->first();

if ($product) {
    // Produk sudah ada → langsung tambah stock
    $product->increment('stock', $quantity);
    $supplierItem->increment('stok', $quantity); // sync juga di supplier
} else {
    // Produk belum ada → hanya tambah di supplier_items
    $supplierItem->increment('stok', $quantity);
}

// Untuk new_items:
// Sama logique: cek existing product sebelum buat
```

## Langkah 2: Modifikasi ProductService (`app/Services/ProductService.php`)

### Tambahkan method baru:
```php
public function getAvailableSupplierItems(int $supplierId)
{
    // Ambil supplier_items yang TIDAK ada di products
    return SupplierItem::where('supplier_id', $supplierId)
        ->where('stok', '>', 0)
        ->whereNotExists(function ($query) use ($supplierId) {
            $query->select(DB::raw(1))
                ->from('products')
                ->whereColumn('products.name', 'supplier_items.name')
                ->where('products.supplier_id', $supplierId);
        })
        ->with('unit')
        ->get()
        ->map(fn ($item) => [
            'id' => $item->id,
            'name' => $item->name,
            'purchase_price' => $item->price,
            'stock' => $item->stok,
            'unit_id' => $item->unit_id,
            'unit_name' => $item->unit?->name,
        ]);
}
```

### Modifikasi method `create()`:
- Field input berubah: `stock` → `margin` (nominal rupiah)
- Harga jual hitung otomatis: `price = purchase_price + margin`

## Langkah 3: Modifikasi ProductController

### Endpoint API baru:
```php
public function getAvailableSupplierItems($supplierId)
{
    $items = $this->productService->getAvailableSupplierItems($supplierId);
    return response()->json($items);
}
```

### Route baru:
```php
Route::get('/products/available-supplier-items/{supplierId}', [ProductController::class, 'getAvailableSupplierItems']);
```
