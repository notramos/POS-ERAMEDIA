# Plan: Redesain UI Keranjang Belanja (Kasir POS)

## Goal
Memperbarui tampilan UI bagian "Keranjang Belanja" pada halaman kasir (`kasir/create.blade.php`) tanpa mengubah logic.

## Current State
- Tampilan list item sederhana dengan:
  - Nama produk, harga x jumlah
  - Input jumlah (quantity)
  - Subtotal per item
  - Tombol hapus
- Input diskon (persentase)
- Metode pembayaran (Tunai/QRIS)
- Ringkasan total (Subtotal, Diskon, Total, Kembalian)

## Redesain yang Diusulkan

### Opsi Desain Modern (lebih detail):
1. **Card-based cart items** - Setiap item dalam card terpisah dengan shadow halus
2. **Visual quantity controls** - Tombol +/- untuk mengatur jumlah dengan animasi
3. **Progress indicator** - Menunjukkan progress menuju minimal transaksi
4. **Quick actions** - Edit quantity dengan slider atau stepper
5. **Empty state** - Ilustrasi kosong yang menarik
6. **Total highlight** - Grand total lebih menonjol dengan gradient
7. **Payment method cards** - Desain card untuk Tunai/QRIS dengan ikon
8. **Animated transitions** - Smooth animation saat add/remove item
